                         # odin-recipes
This project will be my attempt at making a basic recipe website.

It will consist of a main index page which will have links to a few recipes.

It will show knowledge of elements and tags, using an HTML boilerplate working with text using paragraphs
bold and italcized text, lists of recipes with imbedded images including alternate text to describe images
including commit messages during the process of creation to explain why I made changes to certain code.
